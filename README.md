# Mini Banking Management System 🏦

## About
A mini banking database system built with MySQL.

## Tables
- **SIGN_UP** - User authentication (Customer/Admin)
- **ACCOUNT** - Customer bank accounts
- **PAYMENT** - Transaction records

## Features
- Role based users (Customer/Admin)
- Auto balance update using Trigger
- Insufficient balance check (Transaction fails if balance is low)
- Transaction history (Sent & Received)

## Tech Used
- MySQL

## What I Learned
- Database schema design from scratch
- Foreign Keys & Relationships
- Triggers for business logic
- JOIN queries for dashboard data
